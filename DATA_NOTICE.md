# Data Notice

The MIT license in this repository applies only to the source code written for this project.

It does not grant any rights to third-party data, including sports data, odds data, weather data,
or any API responses. That data stays subject to each provider's own terms and licenses.

This repository intentionally contains no third-party datasets, API payloads, database dumps,
or derived data files. Data is stored in private, access-controlled cloud storage.

Sources in use or under evaluation (each provider's terms govern its data):

- nflverse (NFL data)
- CollegeFootballData (NCAAF data)
- The Odds API (sportsbook odds)
- Open-Meteo (weather), with attribution as its license requires
